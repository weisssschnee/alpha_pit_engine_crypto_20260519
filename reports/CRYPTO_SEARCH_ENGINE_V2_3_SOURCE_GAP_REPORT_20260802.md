# Crypto Search Engine V2.3 Source Gap Report

- Reusable and unchanged: 115-field aligned carrier, 786 mechanism catalog,
  CandidateSpec, typed AST/compiler, matched controls, Binance target, mapping,
  frozen 5 bps cost, reward authority, Behavior Archive, and checkpoint state.
- V2.2 defect: validation made random profitability a mandatory survival gate.
- V2.2 ambiguity: only train-top candidates were validated, so proposal-density
  improvement and train-ranker value could not be separated.
- V2.3 minimum change: two fresh seeds, four disjoint validation cohorts,
  paired daily-path attribution, comparator-only random, and an Evolution-only
  continuation gate.
- Explicitly absent: new data, grammar, AST/compiler/evaluator branch, target or
  cost change, imported V2.2 state, HPO, rescue, OOS, or promotion.
